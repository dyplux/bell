# Superseded receipts

These are earlier runs kept for the record. They are **not** what the site
serves — the published receipts live in `bell/site/proof/`.

Two files here once shared a filename and a date with a file in `site/proof/`
while holding different numbers: the 15 September run at 20:36:32Z reported 38
blocked references, the 22:22:00Z run later the same day reported 34. One
identity, two different things, which is the exact failure this project exists
to detect — so the superseded file now carries its observation time in its name.

If you are verifying a published number, use `bell/site/proof/` and `make verify`.
